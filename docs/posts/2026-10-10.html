Google's new work agent calls Claude

Not a model picker — a single agent that routes jobs between Gemini and Anthropic's models across Workspace, M365 and Slack.

What shipped

At Gemini at Work on 8 Oct, Google Cloud launched Gemini agent — one agent for work, not a model picker.

  • Runs across Workspace, Microsoft 365 and Slack
  • Routes jobs between Gemini and Anthropic Claude
  • Aimed at finishing tasks, not answering questions

of large enterprises are already deploying AI agents, per KPMG. The pilot phase is over.

Why routing is the story

Google shipping a product that hands work to a competitor's model tells you where the moat moved.

  • The model is becoming a swappable backend
  • The value sits in orchestration and context
  • Lock-in moves up the stack, not away

The part nobody budgets for

Agent workflows run 5-30x more compute per task than a chatbot query (McKinsey). Routing is a cost lever before it is a quality lever.

  • Cheap model for triage, expensive one for judgement
  • Measure cost per completed task, not per token
  • Build the fallback path before you need it
