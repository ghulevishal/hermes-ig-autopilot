80% of your docs traffic is *not human*.

Mintlify serves documentation for over 20,000 companies. Their co-founder Han Wang put the number on the record: agent traffic went from about 15% of total traffic across the sites they power to 80% over the course of this year.

Your docs became an *interface*

Not a page someone reads. A resource a machine parses mid-task, then acts on.

  • It doesn't scroll, skim or tolerate ambiguity
  • It arrives mid-task with no patience and no context
  • It cannot ask a colleague what you meant

If an agent meets a minor snag during setup, it may try brute force. But it can also just as easily churn to another product.

Optimise for the *machine* reader

Two things now matter more than how the page looks.

  • PAGE SIZE - a huge page eats the agent's context window
  • ACCURACY - a wrong snippet is a lost evaluation
  • One task per page, complete and self-contained
  • Copy-pasteable code that runs without edits
  • Say the version. Agents cannot infer it

Write for the reader that doesn't scroll.
